# Tienda SOAP Service

Este proyecto es un servicio SOAP para gestionar clientes de una tienda.

## Requisitos
- JDK 17
- Apache NetBeans
- Maven

## Ejecución
1. Clona el proyecto e impórtalo en Apache NetBeans.
2. Configura tu base de datos en `application.properties`.
3. Compila y ejecuta el servicio.

## Pruebas con SoapUI
1. Importa el WSDL generado en SoapUI.
2. Realiza peticiones de prueba a los métodos CRUD del servicio.
